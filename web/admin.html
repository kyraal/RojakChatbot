Sentiment analysis

Review sentiment is initially labelled using star ratings (1–2 negative, 3 neutral, 4–5 positive). A TF-IDF + Logistic Regression text classifier is evaluated on a held-out split. Ratings are proxy labels, not human-annotated sentiment.

Select Analyse reviews to calculate the distribution and evaluate the text classifier.

LDA topic modelling

Latent Dirichlet Allocation groups recurring word patterns across the review corpus. Topics are exploratory; interpret the keywords rather than treating them as verified product categories.

Select Discover topics to run LDA on the review dataset.
